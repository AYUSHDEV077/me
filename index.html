v0.1.0CONCEPT SHARD

Braindance.py

A random idea pulled off the Net at 3 a.m.: a Python desktop app that records your coding session — keystrokes, file diffs, terminal output — and replays it as a scrubbable braindance timeline. Rewind the bug. Relive the flatline.

  • Watchdog hooks log every file edit and diff
  • Terminal output captured and tagged as ICE when a traceback hits
  • Replay at 1x–8x and bookmark the moments that mattered
  • Export a session as a shareable datashard
